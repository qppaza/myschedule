Что изменено
1. Рядом с каждым вопросом добавлен значок поиска Google. Он открывает
   поиск в новой вкладке или браузере; копирование осталось рядом.
   На узком экране кнопки расположены столбиком, чтобы не сужать текст.
2. Запрос сохраняет содержательную формулировку вопроса. Дисциплина
   и необходимый фрагмент темы уточняют контекст без лишних повторов.
   Для вопросов законодательства учитывается Республика Беларусь.
   Общие научные вопросы криминологии и криминалистики не получают
   обязательной правовой привязки. Явно указанные другие страны
   сохраняются. Номера статей, годы и источники не придумываются.
3. Внизу перед автором теперь значок Telegram. Иконки автора
   и приложения приведены к одному размеру, текст выровнен.
   Предупреждения разбиты на два компактных абзаца; ссылки
   на официальное расписание и ЭУМК сохранены.

Как обновить GitHub Pages
1. Распакуйте архив.
2. Откройте репозиторий расписания на GitHub → Add file → Upload files.
3. Загрузите ВСЕ 16 файлов из архива в корень репозитория с заменой
   старых. Не добавляйте промежуточную папку.
4. Commit changes; дождитесь публикации GitHub Pages.

Сам ZIP в репозиторий загружать не нужно.
После публикации откройте расписание с интернетом, затем полностью
закройте и откройте снова, чтобы обновился офлайн-комплект v38.
Переустанавливать приложение не требуется.

Проверка
Проверены запросы на материалах разных дисциплин, региональный
контекст, кодирование Google-ссылок, поиск рядом с вопросами,
сохранение исходного текста при копировании, нижние ссылки,
календарные жесты, история панелей и офлайн-комплект.
Данные расписания и вопросов сохранены без изменений.
Использованы DOM, события, координаты и CSS в JSDOM.
Визуальная проверка на физическом телефоне не выполнена.
