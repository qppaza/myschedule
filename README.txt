РАСПИСАНИЕ AMIA · v51 · 16.11.2026

ЛИЧНЫЙ КАБИНЕТ И РЕЖИМ ГОСТЯ
Расписание, учебные вопросы и даты зачётов открыты без регистрации.
Кнопка «Личный кабинет» добавляет вход через Telegram, взятые вопросы
и их историю, общий табель посещаемости, личные оценки и средний балл,
заметки к предмету или дню и настройки напоминаний.

ОБНОВЛЕНИЕ НА GITHUB
1. Распакуйте amia-schedule-v51.zip.
2. Загрузите все 18 файлов в корень репозитория расписания с заменой.
   Загружайте сами файлы, а не ZIP или содержащую их папку.
3. Дождитесь завершения GitHub Pages. Откройте сайт с интернетом.
   Установленное приложение полностью закройте и откройте повторно.
   Офлайн-комплект обновится до v51.
Облачная часть кабинета размещена вместе с Qdropbot в Cloudflare.
На GitHub не нужно загружать исходники бота, токен или списки Telegram ID.

ПЕРВЫЙ ВХОД
Личный кабинет → Войти через Telegram → Продолжить в Telegram.
В Qdropbot нажмите «Начать», сверьте шестизначный код со страницей
расписания и подтвердите вход. Вернитесь в расписание — профиль
откроется автоматически. Вход сохраняется на устройстве на 30 дней.
На общем устройстве после работы нажмите «Выйти».
Аккаунт должен быть в согласованном списке учебной группы.

ПРАВА И ДАННЫЕ
Студент видит табель своей группы и редактирует свои оценки и заметки.
Староста и заместитель редактируют один общий табель своей группы.
Владелец системы имеет доступ ко всем группам и личным кабинетам.
Правки табеля сохраняют автора и время. Конфликт одновременных правок
не перезаписывает чужие изменения: обновите табель и повторите правку.
Взятый вопрос не означает факт ответа или обязательную оценку.
Старые опросы с неполными данными показываются без выдуманных имён.
Личные оценки не изменяют данные бумажного журнала для жеребьёвки.

НАПОМИНАНИЯ
Включаются отдельно в кабинете. Доставка идёт в личные сообщения
Qdropbot, а не в учебные темы. Настраиваются вопросы, зачёты, пороги
неуважительных пропусков и тихие часы. Для доставки откройте бота
и не блокируйте его. Порог 72 часа используется как предупреждение,
а не как автоматическое решение об отчислении.
Кабинету нужен интернет; публичные расписание и материалы сохраняют
прежнюю работу без интернета. Личные ответы API не кэшируются офлайн.

Редактор расписания не изменялся. Архив предыдущего сайта v50
и отдельная инструкция отката сохранены рядом с исходниками проекта.
Глобальная кнопка отката в интерфейс не добавлялась.
