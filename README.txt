Что изменено
1. Одна кнопка темы вместо выпадающей панели. Каждое нажатие переключает
   светлую, тёмную и системную тему. Солнце плавно превращается в луну;
   системный режим обозначен экраном. Выбор сохраняется.
2. «Сегодня» возвращает к текущей дате по времени Минска. Группа и выбранный
   режим «День / Неделя» сохраняются. Надпись об обновлении убрана.
3. Внутри сайта добавлена стеклянная заставка: мягкий фон, эмблема,
   название и анимированная полоса. Цвет соответствует выбранной теме.
   Заставка уходит после готовности страницы, без обязательного ожидания.
4. При медленной сети сохранённое расписание показывается после короткого
   ожидания (до 300 мс после доступа к кэшу); новая копия загружается в фоне.
5. Фон системной заставки Android согласован с фоном страницы.

Как обновить существующий сайт
1. Распакуйте ZIP на телефоне или компьютере.
2. Откройте свой репозиторий qppaza/myschedule на GitHub.
3. В папке, из которой опубликован сайт, нажмите Add file → Upload files.
4. Загрузите с заменой index.html, sw.js и manifest.webmanifest из архива.
   Если публикация настроена из корня репозитория, загружайте в корень.
5. Нажмите Commit changes и дождитесь завершения публикации GitHub Pages.
6. Полностью закройте расписание и откройте его с интернетом заново.

Сам архив ZIP загружать не нужно. Старые файлы удалять не требуется.
Архив содержит полный комплект файлов сайта, включая неизменённые иконки
и manifest-light.webmanifest. Для обновления достаточно трёх файлов выше.

О заставке Android
Первый экран при запуске установленного приложения рисует Android/браузер.
Он поддерживает фон, иконку и название, но не CSS-размытие и не анимацию
Liquid Glass. Новая стеклянная заставка появляется внутри сайта при его
первом отображении. На быстром запуске переход будет коротким.
Изменение системной заставки уже установленного приложения может вступить
в силу с задержкой; при сохранении старого оформления может понадобиться
повторно добавить приложение на главный экран.

Проверка
— Синтаксис встроенных скриптов и sw.js.
— Переключение тем в браузере, сохранение после повторного открытия.
— Режимы «День / Неделя», возврат к сегодняшней дате, выбор группы.
— Мобильная ширина 390 px, светлая и тёмная заставки.
— Автоматическая смена системной темы и работа при запрете localStorage.
— Быстрые повторные нажатия; сохранённый запуск при сбое и медленной сети.
— Данные всех занятий совпадают с исходным опубликованным сайтом.

На реальных Android/iOS-устройствах системный запуск не проверялся.
Этот архив сам по себе не меняет опубликованный сайт.
