Как обновить уже установленную версию v30
1. Распакуйте архив.
2. В репозитории qppaza/myschedule нажмите Add file → Upload files.
3. Загрузите с заменой index.html и sw.js в ту же папку, где находятся
   их прежние версии. Ничего удалять не нужно.
4. Нажмите Commit changes и дождитесь завершения публикации GitHub Pages.
5. Откройте расписание с интернетом, полностью закройте его и откройте
   ещё раз, чтобы загрузилась новая офлайн-копия.

Для этого исправления достаточно двух файлов: index.html и sw.js.
Архив содержит и остальные файлы сайта — они не изменены относительно v30.
Сам ZIP загружать в репозиторий не нужно.
