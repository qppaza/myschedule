РАСПИСАНИЕ AMIA · ИСПРАВЛЕНИЕ v35 · 01.11.2026

Что исправлено
1. Вернулись классические аналоговые часы справа в плашке ближайшего
   занятия: деления, часовая, минутная и секундная стрелки, выделенный
   сектор занятия. Слева выровнены время, дата, предмет и тип занятия;
   таймер и прогресс занимают нижнюю строку по всей ширине.
2. Ползунки при запуске сразу располагаются на выбранном пункте.
   Начальная расстановка, изменение размеров и загрузка шрифта проходят
   без перелёта из нулевой позиции. Анимация остаётся для осознанной
   смены выбранного пункта. Переключатель материалов не пересоздаётся
   при каждой смене типа занятия.
3. Кнопка «Назад» телефона/браузера при открытых материалах сначала
   закрывает панель, сохраняя расписание. Когда панелей нет, «Назад»
   работает как обычно. Закрытие крестиком и жестом удаляет служебную
   запись истории, не накапливая пустые шаги.
4. Обработчик перетаскивания верхней полоски отслеживает движение
   за её пределами и при потере захвата указателя. Добавлен вариант
   для браузеров с touch events без PointerEvent. Короткий жест
   возвращает панель на место, уверенный жест вниз закрывает её.
5. При копировании одного вопроса больше нет всплывающего баннера:
   достаточно галочки в самой кнопке. На Android копирование всего
   списка и запроса для ИИ тоже подтверждается тихо, чтобы не дублировать
   системное уведомление буфера обмена.
6. На остальных платформах сообщение общего копирования стало меньше
   и исчезает примерно через 1,4 секунды. Ошибки копирования сообщаются
   отдельно. Доступное подтверждение для экранного диктора сохранено.
7. Плашка установки снова показывается в обычном браузере после обновления.
   Скрытие старой версии не переносится автоматически. Только явный X
   скрывает новую плашку на неделю; отмена системной установки её не прячет.
   В уже установленном приложении плашка скрыта, инструкция остаётся внизу.

Как обновить GitHub Pages
1. Распакуйте архив.
2. Откройте https://github.com/qppaza/myschedule
3. Add file → Upload files.
4. Загрузите ВСЕ 16 файлов в корень репозитория с заменой старых.
   Файлы должны лежать рядом с index.html, а не в дополнительной папке.
5. Commit changes; дождитесь завершения публикации GitHub Pages.

Сам ZIP в репозиторий загружать не нужно. ui.js и polish.css обязательны:
они входят в полный комплект и используются для панелей и оформления.

Обновление на телефоне
Откройте расписание с интернетом. После публикации полностью закройте
его и откройте снова, чтобы новая офлайн-копия v35 заменила v34.
Переустанавливать приложение не требуется.

Проверка
Проверены классический SVG часов и его стрелки, начальная геометрия
ползунков, отсутствие анимации при resize/font reflow, сохранение
переключателя материалов, история Back/close/reopen, пересекающиеся
закрытия панелей, жесты без pointer capture и touch-only вариант,
тихое копирование и офлайн-комплект. Использованы реальный DOM JSDOM,
события, координаты и управляемые таймеры. Содержимое вопросов и
расписания сверено с предыдущей версией.
Доступ к локальному браузерному предпросмотру был отклонён,
поэтому проверка на физическом телефоне в этой среде не выполнена.
