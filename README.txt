Исправление прокрутки v29 — 17.10.2026

Установка на существующий сайт qppaza.github.io/myschedule/:
1. Распакуйте архив.
2. В папке публикации GitHub Pages замените index.html и sw.js файлами из этого архива.
3. Сохраните изменения (Commit changes) и дождитесь окончания публикации.
4. Закройте вкладку расписания и откройте сайт заново с интернетом.

Сам ZIP загружать не нужно. Остальные файлы сайта не удаляйте.
Это обновление, а не полный автономный сайт.

Что исправлено:
В предыдущей версии правило отключения backdrop-filter проигрывало общему
правилу оформления. Причина — #groups button внутри :is(), повышавший
приоритет общего правила для всех перечисленных элементов, включая карточки.
Отключение стандартного и WebKit-размытия теперь имеет приоритет !important
только на карточках и основных поверхностях страницы. Полупрозрачные заливки,
градиенты, тени и размытие всплывающих окон сохранены.
Обновлена версия офлайн-кэша до v29-backdrop-cascade.
