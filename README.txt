Восстановлен автоматический выбор следующего учебного дня.

После окончания всех занятий расписание автоматически показывает
ближайший следующий день с занятиями выбранной группы. Пустые дни
пропускаются, при необходимости открывается следующая неделя.
Это работает при открытии, на границе окончания последней пары
и после возврата в приложение.

Кнопка «Сегодня» явно показывает сегодняшнюю дату. Ручной выбор дня,
даты в календаре, свайп и переключение недели сохраняют выбор:
автоматика не перескакивает обратно. При переходе на текущую неделю
выбирается сегодняшний день; на другие недели — понедельник.
Перезагрузка страницы или выбор группы включает автоматический выбор.

Как и в прежней логике, занятие без указанного времени окончания
не считается завершённым по предположению. Если следующих занятий
в загруженном расписании нет, остаётся текущий день.

Как обновить GitHub Pages
1. Распакуйте архив.
2. Откройте репозиторий расписания на GitHub → Add file → Upload files.
3. Загрузите ВСЕ 16 файлов из архива в корень репозитория с заменой
   старых. Не добавляйте промежуточную папку.
4. Commit changes; дождитесь публикации GitHub Pages.

Сам ZIP в репозиторий загружать не нужно.
После публикации откройте расписание с интернетом, затем полностью
закройте и откройте снова, чтобы обновился офлайн-комплект v40.
Переустанавливать приложение не требуется.
