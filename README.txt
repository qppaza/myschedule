ВОССТАНОВЛЕНО
Интерфейс BUILD 7: боковая панель «Исходные данные», табличный состав на ПК,
карточки на телефоне, вкладки «Расчёт», «Лаборатория», «Норма», «Документ».
Печатная форма BUILD 7: код страницы, РЦ, заголовок, двухуровневая шапка
таблицы с объединёнными ячейками, примечания, характеристики, органолептика
и физико-химические показатели. Печать длинных рецептур без обрезания.
Сохранены создание любых рецептур, сохранение и восстановление версий,
подбор по цели, справочник сырья, импорт/экспорт JSON, резервная копия, Excel.
Дополнительные свойства сырья находятся под составом в раскрываемом блоке.

РАСЧЁТЫ
Расчётный модуль сохранён из исходника версии 8.1: приложение 12 книги,
504 строки, с. 228–239; линейная интерполяция; предел 50,7 %; сумма СВ всех
компонентов; отдельный прирост по сахарозе; один алгоритм для расчёта и цели.
СВ напитка и сиропа считаются по таблице, не по введённой плотности.
Плотности остаются для массы, массового баланса воды и CO₂.
Количество каждой строки вводится на 1000 дм³ напитка; печать — на партию
без потерь. Сухие вещества жидкого сырья учитывают его плотность.
Для 11,1 и 11,2 % сохранено пояснённое исправление переставленных в книге чисел.
При упаковке 8.1 замена строки номера версии случайно затронула четыре
числа таблицы. В 8.2 восстановлены по исходнику и фотографиям:
0,8 % → 8,00; 1,8 % → 18,09; 19,3 % → 208,02; 30,0 % → 338,09 г/дм³.
Также восстановлены окончания ТУ примера .026 и .022.

ДАННЫЕ
Используется тот же ключ хранения, что в 8.1. Рецептуры, версии и справочник
не удаляются. Из старой BUILD 7 предусмотрен перенос черновика и версий.
Пример «Дюшес» открывается отдельно. Нормы для печати берутся из вкладки «Норма».

ПРОВЕРКА
Пройдены численные тесты и проверки интерфейса в jsdom. Реальный рендеринг
на ПК / Android и визуальная проверка PDF в данной среде не выполнены.
Скачать браузер для этой проверки не удалось. Поэтому точное число страниц
следует проверить в предпросмотре печати для конкретной рецептуры.
