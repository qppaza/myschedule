Как загрузить на GitHub
1. Распакуйте ZIP.
2. Откройте https://github.com/qppaza/myschedule
3. Нажмите Add file → Upload files.
4. Загрузите ВСЕ файлы из архива в корень репозитория с заменой старых.
   Сам ZIP загружать не нужно. Файлы должны лежать рядом с index.html,
   а не внутри дополнительной папки.
5. Нажмите Commit changes и дождитесь обновления GitHub Pages.

Обновление установленного приложения
Откройте расписание с интернетом, затем полностью закройте и откройте
его снова. Обновление офлайн-копии происходит автоматически;
переустанавливать приложение не требуется.

Проверка
Проверены неизменность расписания, привязки вопросов, границы семестров,
перетаскивание и отмена жестов, выбор понедельника, копирование отдельных
вопросов и списка, меню дисциплин, переключение тем и офлайн-кэш.
Интерфейс дополнительно проверен в DOM-среде JSDOM. Геометрия жестов
проверена на событиях и координатах. Полная визуальная проверка в браузере
недоступна в текущей среде; нативная установка проверяется на устройстве.
