РАСПИСАНИЕ AMIA · ОБНОВЛЕНИЕ v36 · 01.11.2026

Что изменено
1. Календарь на телефоне открывается по центру видимой области экрана.
   Учитываются её размер и смещение; в горизонтальном положении
   календарь помещается в экран и при необходимости прокручивается.
   На компьютере календарь располагается возле кнопки и не выходит
   за края окна.
2. Интерфейс календаря стал немного просторнее: крупнее даты, стрелки
   и кнопки. Сетка из шести строк сохраняет размер при смене месяца.
   Появление не масштабирует сетку. Перетягивание выбранной даты,
   клавиатура и отметки выходных сохранены.
3. «Назад» при открытом календаре закрывает его, сохраняя расписание.
   Исправлен также быстрый переход из календаря в материалы:
   служебные записи истории не должны уводить со страницы.
4. Полоска в выборе группы принимает касания: теперь список можно
   потянуть вниз и закрыть той же анимацией, что и материалы.
   Ей мешало старое правило, отключавшее события указателя.
5. Первый показ страницы происходит после подготовки расписания,
   ползунков и плашки установки. Начальные переходы отключены;
   аварийный таймер снимает скрытие, если инициализация не завершилась.
6. При неизменившемся состоянии сохраняются карточки, часы и элементы
   шапки. Возврат в приложение не пересоздаёт их; раскрытые подробности
   и фокус сохраняются. Стрелки часов и таймер продолжают обновляться.
7. Убраны вложенные размытия мелких элементов и изменение фильтров
   при касании перед прокруткой. Стеклянные заливки, блики и тени
   сохранены; постоянное принудительное выделение ползунков в слой
   убрано. Это снижает риск мерцания при мобильной отрисовке.

Классические часы, учебное расписание и вопросы сохранены.

Как обновить GitHub Pages
1. Распакуйте архив.
2. Откройте свой репозиторий расписания на GitHub.
3. Add file → Upload files.
4. Загрузите ВСЕ 16 файлов из архива в корень репозитория с заменой
   старых. index.html и остальные файлы должны лежать рядом, без
   дополнительной вложенной папки.
5. Commit changes; дождитесь публикации GitHub Pages.

Сам ZIP загружать в репозиторий не нужно.

Обновление на телефоне
Откройте расписание с интернетом после публикации, затем полностью
закройте его и откройте снова. Офлайн-комплект v36 заменит предыдущий.
Переустанавливать приложение не требуется.

Проверка
Проверены мобильные и настольные координаты календаря, маленький
экран, изменение visualViewport, история «Назад», переходы между
панелями, жесты выбора группы, сохранение DOM и состояния при
повторной отрисовке, таймер и часы, календарные ползунки, вопросы
и офлайн-комплект. Данные расписания и вопросов сверены с прежней
версией без изменений.
Использованы DOM, события, координаты и управляемые анимации в JSDOM.
Визуальная проверка на физическом телефоне в этой среде не выполнена;
особенности отрисовки конкретного мобильного браузера требуют
проверки на устройстве.
