РАСПИСАНИЕ AMIA · ОБНОВЛЕНИЕ v39 · 02.11.2026

Что изменено
1. Кнопка «Для ИИ» копирует новый подробный запрос для подготовки
   лаконичного и содержательного конспекта. Автоматически подставляются
   дисциплина, вид занятия, все фактические темы выбранных блоков
   и исходные вопросы в прежнем порядке.
2. Удалено задание на самопроверку. Формат ответа ориентирован
   на уверенный развёрнутый ответ: логичные блоки по каждому вопросу,
   ключевые понятия, условия и исключения, выделение важного,
   уместные объясняющие примеры и компактные подтверждённые ссылки.
   Указан ориентир глубины 8–10 баллов без обещания оценки.
3. Добавлены правила для приложенных презентаций, лекций, учебников
   и других материалов: учитывать контекст курса, ссылаться на страницы
   или слайды, отмечать недоступные фрагменты и устаревшие положения.
   Приложить материалы можно в том ИИ-чате, куда вставляется запрос.
4. Правовая часть требует актуального белорусского регулирования
   и применимых действующих ППВС. Иностранные нормы и практика
   отделены от него и допускаются для обозначенного сравнения.
   Для научных вопросов не требуется искусственный перечень НПА.
5. Заданы приоритеты научных, правовых и статистических источников,
   проверка допустимости ресурсов, запрет выдуманных ссылок и сведений,
   честное обозначение отсутствия поиска, полного текста или доступа.
   СудАкт учитывается как российский ресурс, не подтверждающий
   белорусскую судебную практику сам по себе.
6. Обычный поиск Google теперь включает вопрос, полную переданную тему
   и дисциплину. Точные повторы не добавляются. Правила регионального
   контекста сохранены; названия тем не обрезаются.

Как обновить GitHub Pages
1. Распакуйте архив.
2. Откройте репозиторий расписания на GitHub → Add file → Upload files.
3. Загрузите ВСЕ 16 файлов из архива в корень репозитория с заменой
   старых. Не добавляйте промежуточную папку.
4. Commit changes; дождитесь публикации GitHub Pages.

Сам ZIP в репозиторий загружать не нужно.
После публикации откройте расписание с интернетом, затем полностью
закройте и откройте снова, чтобы обновился офлайн-комплект v39.
Переустанавливать приложение не требуется.

тем в одном запросе, отсутствие метаданных, реальные кнопки обычного
