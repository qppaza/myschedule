Что добавлено
1. Кнопки материалов в карточках лекций, семинаров и практических занятий.
   Вопросы открываются в стеклянной панели: на телефоне снизу, на компьютере

   выбор предмета, переключение между лекцией, семинаром и практикой.

   её предлагает, и инструкция для iPhone/iPad, Android и компьютеров.
   Закрытие плашки запоминается на неделю. Инструкция остаётся внизу сайта.
5. Вопросы и интерфейс включены в обязательный офлайн-комплект. Индикатор
   готовности подтверждает, что сохранены и расписание, и материалы.

Содержимое программ
— Перенесены 1209 пунктов из 9 приложенных PDF: 143 темы/фрагмента,
  345 блоков занятий. Это вопросы и планы занятий, а не готовые ответы.
— Тип занятия проверяется строго: лекция не подставляется вместо семинара.
— Нумерация дополнительно сверена с вопросами расписания
  https://uniqlset.github.io/-3-/ : добавлены 165 подтверждённых
  соответствий кодов занятий блокам из PDF. Текст остаётся по программам.
  Если точного сопоставления нет, показаны все вопросы подходящего вида
  занятия в теме и явная пометка об этом. Порядок пар не используется
  для угадывания номера занятия.
— Вопросы без номера темы доступны в каталоге как фрагменты программы.
— У каждого списка указаны исходная программа и страницы PDF.
— Программы местами неполные. Например, в гражданском процессе отсутствуют
  темы 17–36, а в налоговом праве нет темы 8. Вместо выдуманных вопросов
  сайт предлагает открыть доступные темы. Обрывы исходного текста отмечены.
— Расписание, время, преподаватели и аудитории сохранены. Исправлено
  отображение названия «Гражданский процесс», разбитого в исходных данных
  между названием предмета и строкой подробностей.

Как обновить ваш GitHub Pages
1. Распакуйте архив.
2. Откройте репозиторий https://github.com/qppaza/myschedule
3. Нажмите Add file → Upload files.
4. Загрузите с заменой файлы из архива в корень репозитория, где лежит
   index.html. Не загружайте сам ZIP или папку, внутри которой лежат файлы.
5. Нажмите Commit changes и дождитесь публикации GitHub Pages.

Обязательные новые/изменённые файлы:
  index.html
  sw.js
  curriculum.js
  study.js
  study.css
  install.js
  install.css

Остальные иконки и манифесты включены для удобства; они не изменены.
Не загружайте только index.html: ему нужны все пять новых файлов материалов
и установки. Перезагрузка с интернетом обновит установленную офлайн-копию;
переустанавливать приложение не требуется.

Архив сам по себе не меняет опубликованный сайт. В текущей сессии нет
авторизации на запись в ваш GitHub, поэтому файлы подготовлены для загрузки.

Проверка
Синтаксис всех скриптов, неизменность данных расписания, сопоставление всех
занятий с программами и обязательный офлайн-кэш проверены автоматически.
Полная визуальная проверка браузером недоступна в текущей среде:
локальный сервер блокируется сетевой средой, размещённый предпросмотр —
Cloudflare. Установка системного приложения требует проверки на устройстве.
