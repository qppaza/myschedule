РАСПИСАНИЕ AMIA · ОБНОВЛЕНИЕ v34 · 01.11.2026

Что изменено
1. При открытии выбирается текущая дата, включая воскресенье и время
   после завершения пар. На остальных неделях переход начинается с
   понедельника; при возвращении к текущей неделе выбирается сегодня.
   Ручной выбор дня или даты сохраняется до следующей навигации.
2. Светлая тема получила более различимые жемчужные поверхности,
   лавандовые оттенки, чёткие края и более контрастный вторичный текст.
3. Кнопки используют общую реакцию на нажатие. Переключатели материалов,
   дня/недели и календаря объединены плавающим стеклянным ползунком
   с мягкой пружиной и бликами при выборе. Настройка уменьшения движения
   учитывается: лишние анимации в этом режиме отключены.
4. Плашка ближайшего занятия полностью пересобрана: крупное время,
   компактная дата, предмет на всю ширину, тип и окончание занятия,
   таймер и прогресс. Большая колонка аналоговых часов убрана.
5. Верхние полоски в мобильных панелях теперь действуют: потяните вниз,
   чтобы закрыть материалы, выбор группы или инструкцию установки.
   Короткий жест возвращает панель на место. Крестик и Escape также
   используют анимированное закрытие. Полоску можно нажать.
6. Плашка установки приложения пересобрана в адаптивную сетку. На узком
   экране кнопка установки располагается под текстом в отдельном ряду.
7. В верхнем углу показывается только номер группы. Полное название
   действия сохранено для экранных дикторов.
8. Сообщения о копировании появляются отдельной стеклянной плашкой
   поверх открытой панели. Они исчезают примерно через 4 секунды;
   уведомление можно закрыть крестиком или смахнуть в сторону.
9. Таймер обновляется раз в секунду и приостанавливается в скрытой
   вкладке. Переключатели материалов освобождают обработчики после
   закрытия/смены содержимого, без накопления подписок.

Как загрузить на GitHub
1. Распакуйте ZIP.
2. Откройте https://github.com/qppaza/myschedule
3. Нажмите Add file → Upload files.
4. Загрузите ВСЕ 16 файлов из архива в корень репозитория с заменой.
   Они должны лежать рядом с index.html, а не в дополнительной папке.
5. Нажмите Commit changes и дождитесь обновления GitHub Pages.

В этой версии добавлены два обязательных файла: ui.js и polish.css.
Не загружайте только index.html: общие анимации и оформление находятся
в этих новых файлах. Сам ZIP в репозиторий загружать не нужно.

Обновление установленного приложения
Откройте расписание с интернетом, затем полностью закройте и откройте
его снова. Офлайн-копия обновляется автоматически; переустановка
не требуется. Новый комплект кэша включает оба новых файла интерфейса.

Проверка
Проверены текущая дата и смена недель, состояния плашки занятия,
копирование, переключатели, закрытие панелей, повторное открытие во
время анимации, уведомления/таймер/свайп/крестик, управление клавиатурой,
освобождение обработчиков и офлайн-режим. Проверки поведения выполнены
на реальном DOM в JSDOM, жесты и таймеры — на событиях и координатах.
Данные расписания и учебных вопросов сверены с предыдущей версией.
Полная визуальная проверка в браузере недоступна в текущей среде;
нативная установка приложения проверяется на устройстве.
