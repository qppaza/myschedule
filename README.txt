Обновление расписания — 17.10.2026

В архиве два файла для замены на существующем сайте:
  index.html
  sw.js

Как установить:
1. Сохраните резервную копию текущих index.html и sw.js.
2. В репозитории myschedule откройте папку, из которой публикуется GitHub Pages.
3. Через Add file → Upload files загрузите index.html и sw.js из этого архива с заменой одноимённых файлов. Сам архив загружать не нужно.
4. Сохраните изменения (Commit changes), дождитесь завершения публикации GitHub Pages.
5. Перезагрузите сайт. Если остаётся старая версия, закройте вкладку и откройте сайт заново с интернетом.

Не удаляйте остальные файлы сайта: изображения, манифесты и настройки остаются нужны. README загружать не обязательно.

Изменения:
• Полные названия «Информационный час», «Кураторский час», «Информационный и кураторский час» возвращены в заголовки карточек и сводку.
• Обычная смена минуты больше не заменяет весь список карточек. При начале/окончании занятия и переходе на следующий день состояние обновляется.
• Обратный отсчёт и индикаторы прогресса обновляются внутри существующих элементов.
• Плановая пересборка откладывается до короткой паузы в прокрутке.
• Убрано размытие фона на карточках и основных элементах страницы; полупрозрачные заливки, тени и размытие всплывающих окон сохранены.
• Убрана анимация появления карточек и общего контейнера, способная создавать лишние графические слои.
• Повышена версия офлайн-кэша.

Проверено:
• Синтаксис всех трёх встроенных скриптов и sw.js.

• Смена обычной минуты не требует пересборки; начало, окончание занятия и автоматический переход на следующий день требуют обновления.

Ограничение проверки:
На исходном сайте подтверждено исчезновение заголовка. Мерцание не удалось воспроизвести в проверочном браузере. Внесены адресные изменения для устранения возможных причин; результат необходимо проверить на устройстве, где возникает проблема. Полная визуальная проверка исправленной версии на Android/iOS не проводилась.
