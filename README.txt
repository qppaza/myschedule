Что изменено
1. Выделение даты больше не увеличивается и не перелетает за край
   при выборе крайнего дня. Исправлены расчёты дробных размеров
   и масштаба, движение ограничено границами ползунка. Стеклянный
   блик, тень и перетягивание сохранены.
2. Автор и «Приложение» расположены в одной строке, с одинаковыми
   текстовыми метриками и удобными областями нажатия. Перед автором
   добавлен значок академии, соответствующий светлой или тёмной теме.
3. В начале библиотеки материалов добавлена ссылка «Материалы лекций»
   на предоставленную папку Google Диска. Открывается в новой вкладке.
4. Нажатие на название академии в шапке предлагает перейти на её сайт.
   Можно остаться, закрыть предложение крестиком, жестом или «Назад».
   Переход открывает amia.by в новой вкладке.
5. Внизу добавлено предупреждение: вопросы лекций, семинаров
   и практических занятий необходимо сверять с актуальными
   официальными учебными программами. В тексте есть компактные
   ссылки на ЭУМК и официальное расписание академии.

Как обновить GitHub Pages
1. Распакуйте архив.
2. Откройте репозиторий расписания на GitHub → Add file → Upload files.
3. Загрузите ВСЕ 16 файлов из архива в корень репозитория с заменой
   старых. Не добавляйте промежуточную папку.
4. Commit changes; дождитесь публикации GitHub Pages.

Сам ZIP в репозиторий загружать не нужно.
После публикации откройте расписание с интернетом, затем полностью
закройте и откройте снова, чтобы обновился офлайн-комплект v37.
Переустанавливать приложение не требуется.

Проверка
Проверены границы выделения на ширинах 320, 360 и 390 px с дробными
размерами, масштабом и жестами; история и закрытие нового предложения;
выравнивание элементов нижней строки; ссылки, материалы и офлайн-кэш.
Данные расписания и вопросов сохранены без изменений.
Использованы DOM, события, координаты и CSS в JSDOM. Визуальная
проверка на физическом телефоне в этой среде не выполнена.
