РАСПИСАНИЕ AMIA · v46 · 06.11.2026

ВОЗВРАТ ПО ДЕЙСТВИЯМ
Открытие вопросов из занятия в режиме дня или недели — один переход.
Один жест или кнопка браузера «Назад» возвращает к расписанию.
Если после этого открыть «Все темы» и другую тему, возврат проходит
по действительно посещённым экранам в обратном порядке.
Вход через каталог материалов также сохраняет историю переходов.
Переключение вида занятия, копирование и поиск внутри экрана
не создают лишних экранов истории. Раскрытый список закрывается первым.
Крестик, фон и перетягивание панели вниз закрывают всю панель.

ССЫЛКИ НА МАТЕРИАЛЫ
У всех девяти дисциплин есть ссылки на свои папки Google Диска.
У семи дисциплин рядом добавлена ссылка на соответствующий ЭУМК
академии. Для налогового и таможенного права в каталоге академии
отдельные комплексы не найдены, поэтому кнопки для них не добавлены.
В общем каталоге материалов доступна ссылка на общий каталог ЭУМК.

ФОН
Мягкие цветовые переливы в тёмной и светлой теме.
Движение отключается при системном уменьшении анимации
и приостанавливается, когда страница скрыта.

ОБНОВЛЕНИЕ САЙТА
Распакуйте amia-schedule-v46.zip и загрузите все 16 файлов в корень
репозитория GitHub с заменой. Сам ZIP и промежуточную папку не загружайте.
Дождитесь публикации, откройте приложение с интернетом, полностью
закройте и откройте снова для обновления офлайн-комплекта v46.
GitHub автоматически не изменялся.

РЕДАКТОР 1.0.6
В учебных программах можно менять ссылки на папку лекций и ЭУМК
выбранной дисциплины. Кнопка «Сохранить ссылки» сохраняет оба поля.
Можно оставить поле пустым; доступны отмена, повтор и сохранение проекта.
Для ЭУМК принимается ссылка на конкретный комплекс на amia.by.
Старые JSON-проекты и браузерные черновики автоматически не меняются.
Сначала сохраните свой проект, затем откройте ZIP v46 через
«Открыть проект / текущий сайт». Собственные изменения при необходимости
перенесите из сохранённой копии.
Вопросы программ, исправления гражданского и налогового права,
преподаватель Хотько Т.Н. и само расписание сохранены.

ПРОВЕРКА
Автоматически проверены история переходов в реальных сценариях сайта,
ссылки всех дисциплин, работа редактора и офлайн-комплект.
Визуальная проверка на физическом телефоне не выполнялась.
